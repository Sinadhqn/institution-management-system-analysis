# Institution Management System — Systems Analysis and Design

An academic systems analysis and design project focused on analyzing and designing a management system for an educational institution.

The project was developed as part of the **Systems Analysis and Design** course and focuses on identifying organizational problems, defining the proposed system, modeling system processes, analyzing risks, and planning the project.

## Project Overview

The proposed system aims to improve and automate administrative processes within an educational institution, including:

- Student registration and management
- Tuition and payment management
- Class scheduling and management
- Instructor management
- Examination management
- Certificate management
- Communication between branches
- Access to administrative and financial information

The system is designed to reduce manual processes, improve information accessibility, increase operational efficiency, and provide better coordination between students, instructors, staff, and different branches.

## System Analysis and Design

The project includes several system analysis and project management artifacts:

- System Vision Document
- Use Case Diagram
- Activity Diagram
- Data Flow Diagram (DFD)
- Risk Analysis
- Project Planning and Scheduling

## Project Artifacts

### Vision Document
Defines the background, problems, proposed solution, objectives, and expected benefits of the system.

### Use Case Diagram
Models the main actors and their interactions with the proposed system.

### Activity Diagram
Represents the flow of activities within the system.

### Data Flow Diagram
Models the flow of information and processes within the proposed system.

### Risk Analysis
Identifies potential project and system risks and evaluates them based on likelihood, impact, and difficulty.

### Project Planning
Includes project planning and scheduling using Microsoft Project.
